# Repository coding conventions

- Write all new and modified code in English, including directory and file names, identifiers, types, functions, variables, and code comments.
- When working on existing code, rename Spanish code identifiers and paths to clear English names, updating all references, templates, and tests together.
- Keep user-facing Spanish text and existing external contracts compatible unless a coordinated migration is explicitly requested.
- Verify changes with the relevant build and tests.
